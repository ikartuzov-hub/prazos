# Prazos

**Nenhum prazo passa.** Бесплатный сторож дат для ИП в Португалии (trabalhador independente, regime simplificado, доход до 15 000 €/год): человек отвечает на 4 вопроса и получает личный год сроков Segurança Social и Finanças. У каждой даты — что сделать, что будет, если пропустить, основание в законе и метка «сверено / уточняется». Без аккаунта, без рекламы: ответы хранятся только в браузере.

Живое: https://prazos.seedwave.pt/ · сделано SeedWave · автор [Igor Kartuzov](https://www.linkedin.com/in/igor-kartuzov/)

## Поверхности
| Файл | Что это |
|---|---|
| `index.html` (+ `/en/ /ru/ /es/ /de/`) | Приложение: циферблат-сторож, 4 вопроса, лента сроков, правила, .ics, Google Календарь, «Переслать» |
| `flyer.html` (+ языки) | Листовка «Подробнее» |

## Три слоя
- **Движок:** `prazos.js` + `prazos.css` — считает даты (перенос с выходных, праздники PT, окно «Fora de Prazo»), не знает ни языка, ни текста закона.
- **Локали:** `ui.{pt,en,ru,es,de}.json`.
- **Контент:** `data/calendar.json` — каталог обязательств: вид, источник, уверенность, дата сверки. Нет источника — нет в продукте.
- **Реестр:** `manifest.json` → `registry.js`.

## Сборка
```
python3 _src/build.py      # registry.js → пререндер 10 адресов → чек-лист
python3 _src/mkicons.py    # иконки телефона и OG-превью
```
Правка страниц — в `_src/pages/`; корень и языковые папки перезаписываются пререндером.
